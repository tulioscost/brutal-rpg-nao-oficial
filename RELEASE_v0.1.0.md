# BRUTAL RPG — Release v0.1.0

**Sistema não oficial para Foundry Virtual Tabletop**  
**Versão:** 0.1.0  
**Compatibilidade declarada no manifesto:** Foundry VTT 14 (incluindo alvo de desenvolvimento 14.369; validação dentro do aplicativo pendente)

## O que está incluído

- Fichas próprias, em português, para **Sobreviventes** e **Assassinos**, com layout responsivo inspirado em filmes *slasher*.
- Mecânicas iniciais para dados d6, pilhas, manobras, Encontros e Suspenses.
- Oito arquétipos de Sobreviventes, treze tipos de Ameaças e catálogo referencial de Habilidades, Vantagens e Condições.
- Controles de pilhas, Tensão, Horror, Fuga, Passos, Armadilhas e ações gerais; seis macros auxiliares.
- Arquivos de sistema e recursos visuais originais, sem redistribuição integral do livro BRUTAL RPG.

## Arquivos desta Release

1. **`brutal-rpg-v0.1.0.zip`** — pacote de instalação do sistema. Este é o arquivo apontado pelo campo `download` do manifesto.
2. **`system.json`** — manifesto JSON desta versão, para conferência e instalação por endereço da Release.
3. **`RELEASE_v0.1.0.md`** — notas de versão e instruções de instalação (este arquivo).

## Instalação

**Pelo manifesto estável** (após publicar esta Release e o código-fonte na branch `main`):

`https://raw.githubusercontent.com/tulioscost/brutal-rpg-nao-oficial/main/system.json`

No Foundry: **Configuração → Sistemas de Jogo → Instalar Sistema**; use o endereço acima no campo de URL do manifesto.

**Pelo manifesto desta versão:**

`https://github.com/tulioscost/brutal-rpg-nao-oficial/releases/download/v0.1.0/system.json`

**Instalação manual:** descompacte **somente** o conteúdo de `brutal-rpg-v0.1.0.zip` dentro da pasta `Data/systems/brutal-rpg/`, garantindo que `system.json` fique diretamente nessa pasta.

## Limitações conhecidas

Esta é uma **versão inicial**. As regras excepcionais e os efeitos específicos de várias Habilidades e Ameaças exigem adjudicação pela Diretora. Os testes de sintaxe e lógica automatizados foram executados fora do Foundry; **a compatibilidade em uma sessão real do Foundry 14.369 não foi confirmada**.

## Créditos e aviso

Adaptação técnica comunitária, independente e não oficial, baseada em *BRUTAL RPG 0.3*, de Léo “Craw” Naito, Bruce Barbosa e Thales “Bif” Cunha (Editora New Order). O projeto não substitui o livro original nem possui endosso dos autores ou da editora.
